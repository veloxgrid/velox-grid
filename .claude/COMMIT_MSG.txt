feat: Phase 15 - Row State Management (v0.9.0)

RealGrid 스타일의 행 상태 추적 기능 구현

## 구현 내용

### 타입 정의
- RowStateType: 'none' | 'created' | 'updated' | 'deleted' | 'createAndDeleted'
- RowStateManager, ChangesResult 인터페이스
- GridState에 rowStates: Map<RowData, RowStateType> 추가

### 자동 상태 관리
- addRow(): 새 행 → 'created'
- updateRow(): 'none' → 'updated' (created는 유지)
- removeRow(): 'created' → 'createAndDeleted', 기타 → 'deleted'  
- setCellValue(): 셀 수정 시 'none' → 'updated'
- setData(): 모든 행을 'none'으로 초기화

### Public API
- getRowState(index): 인덱스로 행 상태 조회
- getRowStateByData(row): RowData 객체로 상태 조회
- setRowState(index, state): 행 상태 수동 설정
- getChanges(): created, updated, deleted 분리 반환
- getCreatedRows(), getUpdatedRows(), getDeletedRows()
- clearRowStates(): 모든 상태를 'none'으로 초기화
- commit(): 변경사항 확정 (createAndDeleted 제거, 나머지 'none')

## 사용 예시

```typescript
// 행 추가
grid.addRow({ name: 'New User' });
console.log(grid.getRowState(0)); // 'created'

// 행 수정
grid.updateRow(1, { salary: 85000 });
console.log(grid.getRowState(1)); // 'updated'

// 변경사항 확인
const changes = grid.getChanges();
console.log(changes.created.length);  // 1
console.log(changes.updated.length);  // 1

// 서버 저장 후 확정
await saveToServer(changes);
grid.commit();  // 모든 상태 초기화
```
