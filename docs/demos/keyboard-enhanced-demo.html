🎹 Phase 15.1: Keyboard Enhancement

Enhanced keyboard navigation and Quick Edit features

✨ New Features

NEW Quick Edit

  • 타이핑 시 즉시 편집 시작
  • 기존 값 자동 지우기
  • Excel 스타일 편집

IMPROVED Enter Key

  • 모든 Editor에서 동작
  • Enter: 저장 + 아래로
  • Shift+Enter: 저장 + 위로

IMPROVED Tab Key

  • Tab: 저장 + 오른쪽
  • Shift+Tab: 저장 + 왼쪽
  • 연속 편집 가능

1️⃣ Quick Edit (바로 타이핑)

💡 사용 방법:

  • 셀을 선택하고 바로 타이핑하세요 (Enter 불필요)
  • 기존 값이 자동으로 지워지고 새 문자부터 입력됩니다
  • H 입력 → 편집 모드 시작 + "H"부터 입력
  • Esc 취소, Enter 저장

2️⃣ Enter/Tab Navigation

💡 키보드 단축키:

  • Enter - 저장하고 아래 셀로 이동
  • Shift+Enter - 저장하고 위 셀로 이동
  • Tab - 저장하고 오른쪽 셀로 이동
  • Shift+Tab - 저장하고 왼쪽 셀로 이동
  • Esc - 취소하고 편집 종료

3️⃣ Custom Editors with Keyboard

💡 다양한 Editor 타입:

  • Text/Number: Enter/Tab으로 저장 + 이동
  • Select: 드롭다운에서 선택 후 Enter/Tab
  • Date: 날짜 선택 후 Enter/Tab
  • Checkbox: Space로 토글, Enter로 저장 + 이동
