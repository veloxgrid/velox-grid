셀을 클릭하고 키보드 단축키를 사용해보세요. 더블클릭으로 편집할 수 있습니다.

📋 테스트 방법

  1. 편집 후 이동: 셀을 더블클릭하여 편집 모드로 진입 → Enter (아래로), Tab (오른쪽으로), Shift+Tab (왼쪽으로)
  2. Delete 키: 셀을 선택하고 Delete 또는 Backspace 키를 누르면 내용이 삭제됩니다
  3. Undo/Redo: 셀 편집, 삭제, 잘라내기 등의 작업 후 Ctrl+Z로 취소, Ctrl+Y로 다시 실행
  4. 복사/붙여넣기: 셀 선택 후 Ctrl+C → 다른 셀 선택 → Ctrl+V
  5. 전체 선택: 그리드에 포커스를 두고 Ctrl+A
