시작하기

VeloxGrid를 프로젝트에 추가하고 강력한 데이터 그리드를 구현하세요.

npm install velox-grid
import VeloxGrid from 'velox-grid'; import 'velox-grid/dist/velox-grid.css'; const grid = new VeloxGrid({ container: document.getElementById('grid'), columns: [ { field: 'name', header: 'Name', width: 150 }, { field: 'age', header: 'Age', width: 100 } ], data: [ { name: 'John', age: 30 }, { name: 'Jane', age: 25 } ] });
