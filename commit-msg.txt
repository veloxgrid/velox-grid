[Phase 12.1] Cell Validation 기능 추가

구현 내용:
1. ValidationRule, ValidationResult 타입 추가
   - required, min, max, minLength, maxLength, pattern, custom 지원
   
2. GridValidator 모듈 생성 (src/core/GridValidator.ts)
   - validate(): 단일 값 검증
   - validateRow(): 전체 행 검증
   - validateAll(): 전체 데이터 검증
   
3. VeloxGrid.ts 통합
   - endEdit() 메서드에 validation 로직 추가
   - 검증 실패 시 셀에 invalid 스타일 적용
   - onValidationError 이벤트 추가
   
4. CSS 스타일 추가
   - .velox-cell--invalid: 빨간 테두리 + 연한 빨간 배경
   - .velox-validation-tooltip: 에러 메시지 툴팁
   
5. 테스트 파일 추가
   - examples/validation-test.html: 3가지 시나리오 데모

주요 기능:
- 필수 입력 검증 (required)
- 숫자 범위 검증 (min/max)
- 문자열 길이 검증 (minLength/maxLength)
- 정규식 패턴 검증 (pattern)
- 커스텀 validator 함수 (custom)
- 다른 필드 참조 가능 (예: 비밀번호 확인)
