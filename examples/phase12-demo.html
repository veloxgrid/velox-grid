🎨 VeloxGrid Phase 12.2: Custom Cell Editor

Select, Date, Checkbox, Number 등 다양한 커스텀 에디터 데모

📋 Demo 1: Select 에디터 (단일 선택 & 다중 선택)

기능

  • Role 컬럼: 단일 선택 Select 에디터
  • Skills 컬럼: 다중 선택 Select 에디터 (Ctrl/Cmd + Click)
  • 셀을 더블클릭하여 편집 모드 진입
  • Select 변경 시 자동 저장

📅 Demo 2: Date & Number 에디터

기능

  • Birth Date: HTML5 Date Picker
  • Quantity: Number 에디터 (min: 1, max: 999, step: 1)
  • Price: Number 에디터 (min: 0, step: 0.01)
  • Enter 키로 저장, Escape 키로 취소

✅ Demo 3: Checkbox & 혼합 에디터

기능

  • Active: Checkbox 에디터 (클릭 시 즉시 저장)
  • Status: Select 에디터
  • Priority: Number 에디터 (1-5 범위)
  • Due Date: Date 에디터
  • 다양한 에디터 타입이 하나의 그리드에서 작동
// Select 에디터 예제 { field: 'role', header: 'Role', editable: true, editor: { type: 'select', options: [ { value: 'developer', label: 'Developer' }, { value: 'designer', label: 'Designer' }, { value: 'manager', label: 'Manager' } ] } } // 다중 선택 Select { field: 'skills', header: 'Skills', editable: true, editor: { type: 'select', multiple: true, options: [...] } } // Date 에디터 { field: 'birthDate', header: 'Birth Date', editable: true, editor: { type: 'date' } } // Number 에디터 { field: 'quantity', header: 'Quantity', type: 'number', editable: true, editor: { type: 'number', min: 1, max: 999, step: 1 } } // Checkbox 에디터 { field: 'active', header: 'Active', editable: true, editor: { type: 'checkbox' } }
