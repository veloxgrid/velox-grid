🎨 VeloxGrid Phase 14.1: Special Column Display Order

displayOrder를 사용하여 특수 컬럼(CheckBar, RowNumbers, DragHandle)의 표시 순서를 제어합니다.

1️⃣ Default Order (displayOrder 미설정)
설정: 모든 특수 컬럼 활성화, displayOrder 미지정
결과: 기본 순서 - DragHandle (0) → CheckBar (10) → RowNumbers (20)
[ ☰ ][ ✓ ][ # ][ 데이터 컬럼들... ]
💡 기본 displayOrder: DragHandle = 0, CheckBar = 10, RowNumbers = 20
2️⃣ Custom Order: CheckBar 먼저
설정: CheckBar(0) → RowNumbers(10) → DragHandle(20)
결과: CheckBar가 가장 왼쪽에 배치
[ ✓ ][ # ][ ☰ ][ 데이터 컬럼들... ]
코드: checkBar: { visible: true, displayOrder: 0 }
3️⃣ Custom Order: RowNumbers 먼저
설정: RowNumbers(0) → DragHandle(10) → CheckBar(20)
결과: RowNumbers가 가장 왼쪽에 배치
[ # ][ ☰ ][ ✓ ][ 데이터 컬럼들... ]
코드: showRowNumbers: { visible: true, displayOrder: 0 }
4️⃣ Negative Order: 역순 배치
설정: RowNumbers(20) → CheckBar(10) → DragHandle(0) (음수 사용 가능)
결과: 기본 순서의 정확한 반대
[ # ][ ✓ ][ ☰ ][ 데이터 컬럼들... ]
💡 TIP: displayOrder는 음수, 0, 양수 모두 사용 가능하며, 작은 숫자가 왼쪽에 배치됩니다.
