fix: sync header/body scroll and hide fixed area scrollbars

스크롤 동기화 문제 수정:

1. 헤더-바디 가로 스크롤 동기화
   - attachEvents()에서 headerElement.scrollLeft 동기화 추가
   - body 스크롤 시 header도 같이 스크롤되도록 수정

2. Fixed 영역 스크롤바 제거
   - Fixed Left/Right에 스크롤바가 나타나지 않도록 CSS 수정
   - scrollbar-width: none (Firefox)
   - -ms-overflow-style: none (IE/Edge)
   - ::-webkit-scrollbar { display: none } (Chrome/Safari)

3. 헤더 overflow 명시적 설정
   - overflow-x: hidden으로 가로 스크롤바 숨김
   - overflow-y: hidden으로 세로 스크롤 방지

수정 파일:
- src/core/VeloxGrid.ts (스크롤 동기화 로직)
- src/styles/_header.css (헤더 overflow)
- src/styles/_base.css (Fixed 영역 스크롤바 숨김)

결과:
- 헤더와 바디의 가로 스크롤이 완벽히 동기화됨
- Fixed Left/Right에 스크롤바가 나타나지 않음
- 메인 body 영역의 스크롤바만 표시됨
