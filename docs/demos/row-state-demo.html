행을 추가, 수정, 삭제하면 자동으로 상태가 추적됩니다. 각 행은 none, created, updated, deleted, createAndDeleted 상태를 가질 수 있습니다.

💡 Tip: 행의 배경색으로 상태를 구분할 수 있습니다.
  • 🟢 초록색 배경: Created (새로 추가된 행)
  • 🟠 주황색 배경: Updated (수정된 행)
  • 🔴 빨간색 배경: Deleted (삭제된 행, 취소선)

Demo 3: Created → Deleted 동작

새로 추가한 행(created)을 삭제하면 createAndDeleted 상태가 되어 서버 동기화 시 무시됩니다. 이는 서버에 존재하지 않는 데이터이므로 DELETE 요청이 불필요하기 때문입니다.
