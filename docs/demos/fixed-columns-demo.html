🔒 VeloxGrid Phase 14: Fixed Columns

RealGrid 스타일의 Fixed Columns 기능 (fixedOptions)

📌 Phase 14 주요 기능

  • fixedOptions.colCount: 왼쪽에서부터 N개 컬럼 고정
  • fixedOptions.rightCount: 오른쪽에서부터 N개 컬럼 고정
  • 특수 컬럼 처리: CheckBar, RowNumbers, DragHandle은 항상 왼쪽 고정
  • 스크롤 동기화: Fixed 영역과 Scrollable 영역의 세로 스크롤 동기화
  • API: setFixedOptions(), getFixedOptions()

1️⃣ Left Fixed (colCount: 2)

처음 2개 데이터 컬럼을 왼쪽에 고정합니다.

2️⃣ Right Fixed (rightCount: 1)

마지막 1개 컬럼을 오른쪽에 고정합니다.

3️⃣ Both Fixed (colCount: 2, rightCount: 1)

왼쪽 2개, 오른쪽 1개 컬럼을 고정합니다.

4️⃣ With Special Columns (CheckBar + RowNumbers + Fixed)

특수 컬럼과 함께 사용하는 경우입니다.
