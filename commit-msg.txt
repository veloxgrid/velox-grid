feat(phase14.1): add special column display order v0.8.1

특수 컬럼(CheckBar, RowNumbers, DragHandle)의 표시 순서를 제어할 수 있는 displayOrder 옵션 추가

구현 내용:
- CheckBarOptions에 displayOrder 추가
- RowNumbersOptions 인터페이스 추가 (visible, displayOrder)
- RowDragOptions 인터페이스 추가 (enabled, displayOrder)
- showRowNumbers와 rowDraggable이 boolean | Object 지원
- getSpecialColumnsWithOrder() 메서드로 displayOrder 기반 정렬
- getFixedLeftColumns()와 getScrollableColumns()에서 정렬 적용

기본 displayOrder:
- DragHandle: 0 (가장 왼쪽)
- CheckBar: 10 (중간)
- RowNumbers: 20 (가장 오른쪽)

사용 예시:
```typescript
// CheckBar를 가장 왼쪽에
{
  checkBar: { visible: true, displayOrder: 0 },
  showRowNumbers: { visible: true, displayOrder: 10 },
  rowDraggable: { enabled: true, displayOrder: 20 },
}
```

Backward Compatibility:
- showRowNumbers: true → { visible: true, displayOrder: 20 }
- rowDraggable: true → { enabled: true, displayOrder: 0 }
- checkBar: { visible: true } → displayOrder: 10
